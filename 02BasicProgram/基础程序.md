## 学习路径

### 第一个程序：LED闪烁

#### 硬件连接

```plaintext
STM32F103C8T6 最小系统板:
- PC13: 连接LED(板载)
- 无需额外接线
```

#### 使用STM32CubeIDE创建工程

**步骤1: 新建工程**
```
File → New → STM32 Project
选择: STM32F103C8Tx
Project Name: 01_LED_Blink
```

**步骤2: 配置GPIO**
```
Pinout & Configuration → System Core → GPIO
PC13: GPIO_Output (LOW)
```

**步骤3: 修改代码**

在 `main.c` 的 `main()` 函数中添加:

```c
int main(void)
{
  // ... HAL初始化代码 ...

  while (1)
  {
    HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
    HAL_Delay(500);  // 500ms延时
  }
}
```

**步骤4: 编译下载**
```
Project → Build Project
Debug → Download
```

#### 代码详解

```c
// 点亮LED
HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_SET);   // 置位，LED灭(取决于电路)
// 或
HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_RESET); // 复位，LED亮

// 翻转LED状态
HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);

// 读取按键状态
GPIO_PinState state = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0);
```

### 第二个程序：按键控制LED

#### 硬件连接

```plaintext
开发板: STM32F103C8T6
PA0: 连接按键(BOOT0引脚作为按键使用需注意)
或外接按键:
PA0 ──┬─── VCC(3.3V)
      │
      ↓
    按键
      │
     GND
(需要下拉电阻或使用内部下拉)
```

#### 代码实现

```c
#include "main.h"

int main(void)
{
  HAL_Init();

  // 使能GPIO时钟
  __HAL_RCC_GPIOA_CLK_ENABLE();
  __HAL_RCC_GPIOC_CLK_ENABLE();

  // 配置LED引脚(PC13)
  GPIO_InitTypeDef GPIO_InitStruct = {0};
  GPIO_InitStruct.Pin = GPIO_PIN_13;
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);

  // 配置按键引脚(PA0 - 内部上拉)
  GPIO_InitStruct.Pin = GPIO_PIN_0;
  GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
  GPIO_InitStruct.Pull = GPIO_PULLUP;
  HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

  while (1)
  {
    // 读取按键状态(低电平有效则反转逻辑)
    if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET)
    {
      HAL_Delay(20);  // 消抖
      if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET)
      {
        HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
        // 等待按键释放
        while (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET);
      }
    }
  }
}
```

### 第三个程序：串口通信

#### 硬件连接

```plaintext
STM32F103 → USB转TTL模块
PA9(TX)  → RX
PA10(RX) → TX
GND      → GND
```

#### 代码实现

```c
#include "main.h"
#include <stdio.h>

UART_HandleTypeDef huart1;

// 重定向printf到串口
int fputc(int ch, FILE *f)
{
  HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
  return ch;
}

void SystemClock_Config(void);
void MX_GPIO_Init(void);
void MX_USART1_UART_Init(void);

int main(void)
{
  HAL_Init();
  SystemClock_Config();
  MX_GPIO_Init();
  MX_USART1_UART_Init();

  printf("Hello STM32!\r\n");

  uint8_t rx_data;
  while (1)
  {
    // 接收一个字节
    if (HAL_UART_Receive(&huart1, &rx_data, 1, 1000) == HAL_OK)
    {
      // 回显
      printf("Received: 0x%02X\r\n", rx_data);
    }
  }
}

// USART1初始化(115200, 8N1)
void MX_USART1_UART_Init(void)
{
  huart1.Instance = USART1;
  huart1.Init.BaudRate = 115200;
  huart1.Init.WordLength = UART_WORDLENGTH_8B;
  huart1.Init.StopBits = UART_STOPBITS_1;
  huart1.Init.Parity = UART_PARITY_NONE;
  huart1.Init.Mode = UART_MODE_TX_RX;
  huart1.Init.HwFlowCtl = UART_HWCONTROL_NONE;
  huart1.Init.OverSampling = UART_OVERSAMPLING_16;
  if (HAL_UART_Init(&huart1) != HAL_OK)
  {
    Error_Handler();
  }
}
```

### 第四个程序：定时器中断

#### 定时器配置示例

```c
// 在main函数中配置定时器2(1ms中断)
void MX_TIM2_Init(void)
{
  TIM_ClockConfigTypeDef sClockSourceConfig = {0};
  TIM_MasterConfigTypeDef sMasterConfig = {0};

  htim2.Instance = TIM2;
  htim2.Init.Prescaler = 7200 - 1;      // 72MHz / 7200 = 10KHz
  htim2.Init.CounterMode = TIM_COUNTERMODE_UP;
  htim2.Init.Period = 10 - 1;           // 10KHz / 10 = 1KHz (1ms)
  htim2.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
  htim2.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_ENABLE;
  if (HAL_TIM_Base_Init(&htim2) != HAL_OK)
  {
    Error_Handler();
  }

  sClockSourceConfig.ClockSource = TIM_CLOCKSOURCE_INTERNAL;
  if (HAL_TIM_ConfigClockSource(&htim2, &sClockSourceConfig) != HAL_OK)
  {
    Error_Handler();
  }

  sMasterConfig.MasterOutputTrigger = TIM_TRGO_RESET;
  sMasterConfig.MasterSlaveMode = TIM_MASTERSLAVEMODE_DISABLE;
  if (HAL_TIMEx_MasterConfigSynchronization(&htim2, &sMasterConfig) != HAL_OK)
  {
    Error_Handler();
  }

  // 使能定时器中断
  HAL_TIM_Base_Start_IT(&htim2);
}

// 定时器中断回调函数
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim->Instance == TIM2)
  {
    // 每1ms执行一次
    static uint32_t ms_count = 0;
    ms_count++;
  }
}
```

## 常见问题

### Q1: 下载后程序不运行

**排查步骤**:
1. 检查BOOT0引脚是否接地
2. 确认时钟配置正确
3. 查看是否进入HardFault_Handler
4. 检查是否正确链接.startup文件

### Q2: 串口输出乱码

**常见原因**:
- 波特率不匹配
- 引脚配置错误(TX/RX反了)
- TTL vs RS232电平不匹配

### Q3: LED不亮

**检查要点**:
- LED极性是否正确(长脚为阳极)
- 限流电阻是否需要
- 引脚是否配置为输出模式

### Q4: 按键按下无响应

**排查方法**:
1. 检查硬件连接
2. 确认GPIO模式(上拉/下拉)
3. 检查消抖延时

// 使用定时器PWM输出

HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);

while (1)
{
  for (uint16_t i = 0; i <= 255; i++)
  {
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, i);
    HAL_Delay(10);
  }
  for (uint16_t i = 255; i > 0; i--)
  {
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, i);

}
