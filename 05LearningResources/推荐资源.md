## 学习路线推荐

### 入门路线(6个月)

```
Month 1-2: C语言基础 + 51单片机
    ↓
Month 3-4: STM32 + 基础外设(GPIO/中断/定时器/UART)
    ↓
Month 5-6: 基础项目实战(小制作/智能车基础)
```

### 进阶路线(6-12个月)

```
继续深入:
├─ RTOS (FreeRTOS)
├─ 通信协议 (I2C/SPI/CAN)
├─ 简单无线 (BLE/WiFi)
└─ 基础项目 (无人机/小车)
```

### 高级路线(12个月+)

```
深入方向:
├─ Linux驱动开发
├─ 异构计算 (DSP/RISC-V)
├─ 行业深入 (汽车电子/工业)
└─ 系统架构设计
```

## 持续学习建议

1. **保持动手**: 嵌入式是实践学科，多做项目
2. **阅读源码**: 优秀开源项目是最好教材
3. **关注行业**: 订阅技术博客，了解最新动态
4. **参与社区**: 解决问题，分享经验
5. **英语能力**: 官方文档多为英文，技术英语很重要
