## ⭐ 资源使用建议

### 按周学习计划

| 周次 | 目标 | 配套资源 |
|------|------|----------|
| 1-2周 | 环境搭建 + C基础 | 菜鸟教程 + LeetCode |
| 3-4周 | STM32 GPIO + 串口 | 正点原子P1-P20 |
| 5-6周 | 定时器 + 中断 | 野火中断章节 |
| 7-8周 | I2C/SPI通信 | 正点原子通信教程 |
| 9-12周 | FreeRTOS | 野火FreeRTOS |
| 13-16周 | 综合项目 | 自行设计 |
| 17-24周 | 进阶Linux/项目 | 韦东山Linux |

### 资源筛选原则

1. **官方文档优先**: 芯片手册、Datasheet是最准确的
2. **视频+文档结合**: 看视频入门，查文档深究
3. **动手实践**: 只看不练 = 不会
4. **英语很重要**: 官方文档90%是英文
