## 行业概况

### 嵌入式系统应用领域

| 领域 | 典型产品 | 薪资范围(参考) |
|------|----------|----------------|
| 消费电子 | 智能手表、音箱、耳机 | 10-25K |
| 汽车电子 | 车载系统、ADAS、域控制器 | 15-35K |
| 工业控制 | PLC、伺服驱动、工业机器人 | 12-28K |
| 物联网 | 智能家居、传感器、网关 | 10-25K |
| 通信设备 | 路由器、交换机、基站 | 12-30K |
| 医疗器械 | 监护仪、诊断设备 | 15-35K |
| 航空航天 | 飞控系统、卫星导航 | 20-50K |

### 行业发展趋势

- **异构计算**: ARM+RISC-V+DSP多核架构
- **RTOS普及**: FreeRTOS、RT-Thread、Zephyr应用广泛
- **AI边缘化**: 嵌入式AI部署(NPU/TPU)
- **安全要求**: IEC 61508、ISO 26262功能安全
- **开源硬件**: RISC-V生态快速发展

## 职业发展阶段

### 初级工程师(0-2年)

**典型岗位**: 嵌入式软件工程师、初级驱动工程师

- 负责简单模块的开发
- 理解产品需求，完成功能实现
- 配合测试进行问题定位
- 薪资区间: 8-18K

### 中级工程师(2-5年)

**典型岗位**: 高级嵌入式软件工程师、系统工程师

- 独立负责产品模块设计
- 解决复杂技术问题
- 指导初级工程师
- 负责代码Review
- 薪资区间: 15-30K

### 高级工程师(5-8年)

**典型岗位**: 技术专家、team leader、架构师

- 负责产品系统架构设计
- 制定技术方案和选型
- 团队技术指导
- 与硬件/算法团队协作
- 薪资区间: 25-45K

### 专家/管理层(8年+)

**典型岗位**: 技术总监、部门经理、首席工程师

- 制定技术战略
- 团队管理和人才培养
- 行业技术影响力
- 推动技术创新
- 薪资区间: 40K+

## 就业方向

### 企业类型

| 企业类型 | 特点 | 适合人群 |
|----------|------|----------|
| 芯片原厂(NXP/ST/瑞芯微等) | 技术深度高、SDK开发 | 追求技术专家路线 |
| 终端产品公司(小米/大疆/华为) | 产品-oriented、全栈能力 | 综合能力强 |
| 汽车零部件(博世/采埃孚) | 流程规范、功能安全 | 追求稳定发展 |

| 研究所/国企 | 稳定、项目独特 | 追求 Work-Life Balance |

## 附录：常见面试题

### C语言基础

1. 指针和引用的区别
2. volatile关键字的作用
3. static关键字的作用
4. 宏定义和函数的区别
5. 内存管理(malloc/free)

### 嵌入式基础

1. 中断处理流程
2. 常见通信协议对比
3. I2C/SPI时序
4. ARM cortex-M中断优先级
5. 状态机实现

### RTOS

1. 任务调度算法
2. 死锁产生条件与避免
3. 进程/线程区别
4. 临界区保护
5. 内存溢出检测

### 项目经验(必问)

1. 项目中最有挑战的部分
2. 调试过的最复杂的问题
3. 代码优化经验
4. 团队协作经历
