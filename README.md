## 📋 推荐学习路径 (6 个月速成)

```
第 1-2 周：预备期
├── [ ] 完成 C 语言基础自测
├── [ ] 购买开发板 (STM32F103 ~15 元)
└── [ ] 安装开发工具 (STM32CubeIDE)

第 3-4 周：工具环境
├── [ ] 成功编译第一个工程
├── [ ] 成功烧录到开发板
└── [ ] 串口输出 "Hello World"

第 5-8 周：基础外设
├── [ ] LED 控制 (亮/灭/闪烁)
├── [ ] 按键读取 (轮询 + 中断)
├── [ ] 定时器中断 (精确定时)
└── [ ] 串口通信 (收发数据)

第 9-12 周：通信协议
├── [ ] I2C 驱动 (OLED 屏幕显示)  → 练习项目 4
├── [ ] SPI 驱动 (Flash 读写)
└── [ ] 模拟协议 (软 I2C/软 SPI)

第 13-16 周：RTOS
├── [ ] FreeRTOS 任务创建
├── [ ] 队列通信
└── [ ] 信号量同步

第 17-24 周：综合项目
├── [ ] 完成 1-2 个完整项目
├── [ ] 代码整理到 GitHub
├── [ ] 项目技术文档
└── [ ] 简历准备 + 面试投递
```

> 📌 **完整版**: 见 [学习任务检查清单](00 预备知识/学习任务检查清单.md)

## 🔧 关键成功要素 (80/20 法则)

> 这 20% 的任务会产生 80% 的成效：

1. **第一个 LED 闪烁** → 打通"代码→烧录→运行"全流程，建立信心
2. **串口 printf 重定向** → 最有效的调试手段，解决 80% 的问题
3. **I2C/SPI 驱动编写** → 能移植任意传感器驱动
4. **FreeRTOS 任务 + 队列** → 解决多任务协作
5. **一个完整项目** → 简历和面试的核心筹码

## 📞 常见问题

**Q: 需要买什么开发板？**
A: 入门推荐 `STM32F103C8T6 最小系统 (~15 元)` + `ST-Link 调试器 (~10 元)`

**Q: Keil 还是 CubeIDE？**
A: 入门用 CubeIDE 免费版，进阶可用 Keil，最终推荐 VSCode+EIDE

**Q: C 语言要学到什么程度？**
A: 能独立完成基础算法题 (数组/指针/结构体)，参考检查清单

**Q: 学完能找什么工作？**
A: 初级嵌入式工程师，8-15K，参考 [职业发展路线](04CareerRoadmap/职业发展路线.md)

**Q: 2025 年行业有什么新要求？**
A: 查看 [知识时效性审核报告](00 预备知识/知识时效性审核报告.md)，重点关注 C++17/20、AI 边缘计算、分布式系统
