## 📋 推荐学习路径 (6个月速成)

```
第1-2周: 预备期
├── [ ] 完成C语言基础自测
├── [ ] 购买开发板 (STM32F103 ~15元)
└── [ ] 安装开发工具 (STM32CubeIDE)

第3-4周: 工具环境
├── [ ] 成功编译第一个工程
├── [ ] 成功烧录到开发板
└── [ ] 串口输出 "Hello World"

第5-8周: 基础外设
├── [ ] LED控制 (亮/灭/闪烁)
├── [ ] 按键读取 (轮询+中断)
├── [ ] 定时器中断 (精确定时)
└── [ ] 串口通信 (收发数据)

第9-12周: 通信协议
├── [ ] I2C驱动 (OLED屏幕显示)  → 练习项目4
├── [ ] SPI驱动 (Flash读写)
└── [ ] 模拟协议 (软I2C/软SPI)

第13-16周: RTOS
├── [ ] FreeRTOS任务创建
├── [ ] 队列通信
└── [ ] 信号量同步

第17-24周: 综合项目
├── [ ] 完成1-2个完整项目
├── [ ] 代码整理到GitHub
├── [ ] 项目技术文档
└── [ ] 简历准备 + 面试投递
```

> 📌 **完整版**: 见 [学习任务检查清单](00预备知识/学习任务检查清单.md)

## 🔧 关键成功要素 (80/20法则)

> 这20%的任务会产生80%的成效：

1. **第一个LED闪烁** → 打通"代码→烧录→运行"全流程，建立信心
2. **串口printf重定向** → 最有效的调试手段，解决80%的问题
3. **I2C/SPI驱动编写** → 能移植任意传感器驱动
4. **FreeRTOS任务+队列** → 解决多任务协作
5. **一个完整项目** → 简历和面试的核心筹码

## 💬 学习建议

> **成为工程师，从踏上赛场的那一刻开始！**

- ✅ **实践驱动**: 边做边学，不要等"学完"再动手

- ✅ **协作精神**: 参与贡献，和他人碰撞学习

## 📞 常见问题

**Q: 需要买什么开发板？**  
A: 入门推荐 `STM32F103C8T6 最小系统 (~15元)` + `ST-Link调试器 (~10元)`

**Q: Keil还是CubeIDE？**  
A: 入门用CubeIDE免费版，进阶可用Keil，最终推荐VSCode+EIDE

**Q: C语言要学到什么程度？**  
A: 能独立完成基础算法题(数组/指针/结构体)，参考检查清单

**Q: 学完能找什么工作？**  
A: 初级嵌入式工程师，8-15K，参考 [职业发展路线](04CareerRoadmap/职业发展路线.md)
