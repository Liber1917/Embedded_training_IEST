## 学习路径推荐

### 入门阶段 (0-6个月)

1. **预备知识**: 完成`00预备知识`模块，重点学习提问的智慧
2. **环境搭建**: 完成`01工具链`配置
3. **基础入门**: 完成`02基础程序`前5个示例
4. **第一个项目**: 独立完成LED闪烁/按键检测

### 进阶阶段 (6-12个月)

1. **RTOS学习**: 完成`03操作系统`FreeRTOS内容
2. **通信协议**: 掌握I2C/SPI/CAN
3. **项目实践**: 完成综合性项目(小车/无人机)
4. **职业规划**: 阅读`04职业发展`明确方向

### 高级阶段 (12个月+)

1. **Linux系统**: 嵌入式Linux开发
2. **专业方向**: 汽车电子/IoT/工业控制
3. **持续学习**: 利用`05学习资源`保持进步

## 核心原则

> **成为工程师，从踏上赛场的那一刻开始！**

- ✅ **实践驱动**: 边做边学，不要等"学完"再动手
- ✅ **问题导向**: 带着问题学习，效率更高
- ✅ **协作精神**: 参与贡献，和他人碰撞学习
- ✅ **持续迭代**: 保持学习，跟踪行业趋势
