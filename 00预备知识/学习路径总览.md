### 🎯 每个阶段的核心任务

#### 📍 阶段0: 预备期 (目标: 确定方向，准备工具)
```markdown
- [ ] 完成C语言基础自测 (参考学习检查清单)
- [ ] 购买开发板 (推荐STM32F103最小系统 ~15元)
- [ ] 安装开发工具 (STM32CubeIDE / Keil MDK)
- [ ] 注册GitHub账号
```

#### 📍 阶段1: 环境搭建 (目标: 让开发板跑起来)
```markdown
- [ ] 成功编译第一个工程
- [ ] 成功烧录到开发板
- [ ] 串口输出 "Hello World"
- [ ] Git仓库初始化
```

#### 📍 阶段2: 基础外设 (目标: 掌握基本外设操作)
```markdown
- [ ] LED控制 (亮/灭/闪烁)
- [ ] 按键读取 (轮询+中断)
- [ ] 定时器中断 (精确定时)
- [ ] 串口通信 (收发数据)
```

#### 📍 阶段3: 通信协议 (目标: 能驱动任意传感器)
```markdown
- [ ] I2C驱动 (OLED屏幕显示)
- [ ] SPI驱动 (Flash读写)
- [ ] 模拟协议 (软I2C/软SPI)
```

#### 📍 阶段4: RTOS (目标: 多任务协同)
```markdown
- [ ] FreeRTOS任务创建
- [ ] 队列通信
- [ ] 信号量同步
- [ ] 多任务调试
```

#### 📍 阶段5: 综合项目 (目标: 产出可用于简历的项目)
```markdown
- [ ] 完成1-2个完整项目
- [ ] 代码整理到GitHub
- [ ] 项目技术文档
- [ ] 简历准备
```

## 📞 常见问题FAQ

### Q: 需要买什么开发板？
A: 入门推荐 `STM32F103C8T6 最小系统板` (~15元)，或者 `STM32F407VET6` (~80元)

### Q: Keil还是CubeIDE？
A: 入门用CubeIDE(免费)，进阶用Keil(商业但强大)，最终推荐VSCode+EIDE

### Q: C语言要学到什么程度？
A: 能独立完成基础算法题目(如数组/指针/结构体操作)，参考学习任务检查清单

### Q: 没有硬件怎么做？
A: 可以先用QEMU模拟，或者购买低成本的开发板

### Q: 学完能找什么工作？
A: 初级嵌入式工程师，薪资8-15K，参考职业发展路线文档
