## 📊 知识差距分析

### 过时内容识别

| 现有内容 | 问题描述 | 建议替换/补充 |
|---------|----------|--------------|
| **纯 C 语言路线** | 2025 年嵌入式 C++ 岗位占比 40%+ | 新增**现代 C++ 模块** (C++17/20) |
| **Keil 为主** | 行业向 VSCode + WSL 迁移 | 强化**WSL + Ubuntu + VSCode** |
| **传统 MCU 项目** | 缺少 AI 边缘计算 | 新增**AI 基础**和边缘 AI 部署 |
| **单机思维** | 缺少分布式系统 | 新增**分布式计算入门** |
| **无算法训练** | 仅 C 语言基础 | 引入**labuladong + hello-algo** |

### 缺失内容清单

| 模块 | 说明 | 优先级 |
|------|------|--------|
| **现代 C++ 编程** | C++17/20、RAII、智能指针 | 🔴 高 |
| **AI/GPU 计算** | CUDA 入门、边缘 AI 部署 | 🔴 高 |
| **数据结构系统** | C++ 实现 + labuladong | 🔴 高 |
| **WSL 开发环境** | WSL2 + Ubuntu 配置 | 🟡 中 |
| **分布式系统** | CS149 精简版 | 🟡 中 |
| **面试准备** | 小林 coding 八股文 | 🟡 中 |
| **Python 工具链** | 自动化测试脚本 | 🟢 低 |
