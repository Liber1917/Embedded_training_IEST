## 📚 平台概述

d2learn.org 提供系统化的嵌入式软件开发课程，涵盖从基础到高级的完整学习路径。

### 平台特点

| 特点 | 说明 |
|-----|------|
| **实战导向** | 每个概念都有实际代码示例 |
| **嵌入式专注** | 针对资源受限环境优化 |
| **渐进式学习** | 从基础到高级的清晰路径 |
| **社区支持** | 活跃的学习社区和讨论 |

## 📝 学习建议

### 有效学习方法

1. **先理解概念**：阅读理论部分，理解"为什么"
2. **动手实践**：运行示例代码，尝试修改
3. **完成练习**：独立完成每章的练习题
4. **项目应用**：将所学应用到实际项目中
5. **复习总结**：定期复习，形成知识体系

## 🎯 学习目标检查

完成 d2learn.org 相关课程后，你应该能够：

### 基础检查
- [ ] 理解 C++ 与 C 的核心区别
- [ ] 能够使用 auto 简化代码
- [ ] 理解范围 for 循环的使用场景

### 进阶检查
- [ ] 能够正确使用智能指针
- [ ] 理解 RAII 的原理和应用
- [ ] 能够解释移动语义的优势

### 高级检查
- [ ] 能够使用 Lambda 编写回调
- [ ] 理解完美转发和万能引用
- [ ] 能够将 C 项目重写为现代 C++
