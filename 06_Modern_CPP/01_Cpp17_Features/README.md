## 📖 各特性详细说明

### 1. auto 类型推导

**文件**: [`auto_type.md`](./auto_type.md)

**核心问题**：减少冗余的类型声明，提高代码可读性

**关键内容**：
- `auto` 基本语法
- 与 `const`、引用组合使用
- 在嵌入式中的应用场景
- 常见陷阱

---

### 2. RAII (Resource Acquisition Is Initialization)

**文件**: [`raii.md`](./raii.md)

**核心问题**：如何确保资源（内存、文件、锁）总是被正确释放？

**关键内容**：
- RAII 核心思想
- 手写 RAII 类
- 在嵌入式系统中的应用
- 与 C 风格资源管理对比

---

### 3. 智能指针

**文件**: [`smart_pointers.md`](./smart_pointers.md)

**核心问题**：如何避免内存泄漏和悬空指针？

**关键内容**：
- `std::unique_ptr` - 独占所有权
- `std::shared_ptr` - 共享所有权
- `std::weak_ptr` - 打破循环引用
- 自定义删除器（嵌入式重要）

---

### 4. 移动语义

**文件**: [`move_semantics.md`](./move_semantics.md)

**核心问题**：如何避免不必要的深拷贝，提高性能？

**关键内容**：
- 左值 (lvalue) vs 右值 (rvalue)
- 移动构造函数
- 移动赋值运算符
- `std::move` 的正确使用

---

### 5. Lambda 表达式

**文件**: [`lambda.md`](./lambda.md)

**核心问题**：如何简洁地定义匿名函数，特别是回调函数？

**关键内容**：
- Lambda 基本语法
- 捕获列表详解
- 在嵌入式回调中的应用
- 与 `std::function` 配合使用
