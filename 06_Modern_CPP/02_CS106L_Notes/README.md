## 📚 课程概述

CS106L 是斯坦福大学开设的现代 C++ 编程课程，专注于 C++ 标准库和最佳实践。

### 课程特点

| 特点 | 说明 |
|-----|------|
| **实用性** | 聚焦实际工作中常用的 C++ 特性 |
| **现代化** | 强调 C++11/14/17 新特性 |
| **简洁性** | 教授如何写出简洁、可读的代码 |
| **安全性** | 强调类型安全和内存安全 |

## 🎯 与本课程的关系

本培训体系的 `06_Modern_CPP` 模块大量参考了 CS106L 的内容，并针对嵌入式系统进行了适配。

```
┌─────────────────────────────────────────────────────────────┐
│              CS106L → IEST 嵌入式培训体系                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  CS106L 通用 C++              IEST 嵌入式 C++                │
│                                                             │
│  • 标准库容器              →  • 嵌入式内存受限场景           │
│  • 通用算法                →  • 实时性要求                  │
│  • 桌面应用示例            →  • 嵌入式外设示例              │
│  • 性能优化                →  • 确定性行为                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
