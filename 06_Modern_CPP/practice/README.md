## 🔧 编译环境

```bash

g++ --version  # GCC 9+ 或 Clang 10+

# 编译标志
-std=c++17 -Wall -Wextra -Wpedantic

# 内存检查（可选）
valgrind --leak-check=full ./program
```

## 💡 学习建议

3. 频繁编译测试

2. 代码审查
3. 与参考答案对比
